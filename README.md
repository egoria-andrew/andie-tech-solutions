# Andie Tech Solutions

Official website for **Andie Tech Solutions** — campus-focused IT support and digital services at Gulu University, Uganda.

**Live site:** https://egoria-andrew.github.io/andie-tech-solutions/

## Services

- Operating-system installation and software setup
- Password and access recovery
- Eduroam connection and basic network troubleshooting
- Laptop repair and upgrades
- Static portfolio websites, personal websites, and landing pages

## Project structure

```text
├── index.html       # Public home page
├── fixes.html       # Quick Fixes page
├── 404.html         # Page shown for missing links
├── style.css         # Shared styles
├── assets/          # Logo, hero artwork, and favicon
└── docs/            # Maintenance and deployment documentation
```

## Versions

- **Version 1** — original website design, preserved in Git history.
- **Version 2** — current branded, responsive design.

See [CHANGELOG.md](CHANGELOG.md) for release notes and the `docs` folder for maintenance guidance.

## Updating the site

1. Make changes in a separate Git branch.
2. Check links, phone numbers, prices, and mobile layout.
3. Merge approved work into `main`.
4. GitHub Pages publishes the updated site from the configured source branch.

Do not commit passwords, API keys, private customer information, or other sensitive data to this repository.
