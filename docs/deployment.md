# Deployment

## Hosting

The public website is hosted with GitHub Pages.

**Current address:** https://egoria-andrew.github.io/andie-tech-solutions/

## Publishing changes

1. Create a branch for the change, for example `update-service-prices`.
2. Edit and test the files locally.
3. Commit the change with a clear message.
4. Merge the approved branch into `main`.
5. Confirm the GitHub Pages deployment has completed in the repository’s **Settings → Pages** area.
6. Test the public site on a phone and desktop browser.

## Custom domain (future)

To use an address such as `andietechsolutions.com`, buy the domain from a domain registrar, add it in **Settings → Pages → Custom domain**, then add the DNS records GitHub provides at the domain registrar. Enable HTTPS after DNS verification.

Keep the `CNAME` file if GitHub Pages creates one for the custom domain.
